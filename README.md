# megutabi-site

> このリポジトリは **公開用の配信ミラー**です。GitHub Pages 配信のためだけに存在します。

ソースの正本は非公開リポジトリ [`megutabi`](https://github.com/kyamada23/megutabi) の `site/` ディレクトリです。編集はそちらで行い、`bash scripts/publish_site.sh` で本リポジトリへ反映します。**本リポジトリを直接編集しないでください**（履歴が分岐し、次回 publish が失敗します。復旧は正本側の `docs/site-publishing.md` を参照）。
