# ハンドオフ: 公式サイト改修（実数表記修正 + テーマページ第1弾「現存12天守」）

対象リポジトリ: megutabi-site（GitHub Pages）
実行モード: plan-mode-first（実装前に計画を提示し、承認を得てから着手）
推奨モデル: Sonnet（スコープ確定済みの実装）


## 背景と目的

公式サイトは現在 LP 1枚 + 法務ページのみで、LP に「18テーマ収録」という古い表記が残っている（実態はテーマ73 / スポット260 / 全47都道府県）。
本タスクは (1) 表記の実数修正、(2) SEO 資産となるテーマ紹介ページの第1弾「現存12天守」の追加、の2点。

テーマページは今後 seed データから自動生成する構想があるが、本タスクでは自動生成スクリプトは作らない。まず1本を手作りで公開し、検索結果への載り方を確認してからスクリプト化を別 PBI で判断する。

## Scope

### 修正

- LP（index.html）: 「18テーマ」等の収録数表記を「73テーマ・260スポット・全47都道府県」に更新（文言の位置・見せ方は既存デザインを踏襲。実数はアプリ側 seed の最新値を正とし、着手時に要確認）

### 新規

- /themes/genzon-12-tenshu.html（またはサイトの既存構成に合わせたパス）: 下記原稿を HTML 化
- sitemap.xml: 無ければ新規作成（LP・法務ページ・新ページを含む）。あれば新ページを追記
- LP から新ページへの内部リンクを1箇所追加（例: 「収録テーマの例: 現存12天守」）

### やらないこと

- テーマページの自動生成スクリプト（別 PBI）
- 他テーマのページ追加（本タスクは1本のみ）
- サイトデザインの刷新・CSS フレームワーク導入
- OGP 画像の新規制作（暫定は既存のアプリアイコン等を流用。専用画像は別タスク）

## ファイルスコープ

修正・新規あわせて 4ファイル以内（index.html / themes/genzon-12-tenshu.html / sitemap.xml / 共通CSSを触る場合のみ+1）。超える場合は計画段階で報告し承認を待つ。

## 技術要件

- 各ページに固有の `<title>` と `<meta name="description">`（原稿に指定あり）
- 構造化データ: ItemList（JSON-LD）で12城を列挙
- OGP タグ（og:title / og:description / og:url / og:image）
- スマホ表示を優先（アプリ流入の主導線が X → モバイル閲覧のため）
- 英語ラベル不使用（アプリと同方針）

## 停止条件

- 主要ブラウザ相当のローカルプレビューでレイアウト崩れがないこと
- 全内部リンクが有効であること
- HTML の構文エラーがないこと
- 原稿の文言は改変しない。HTML 化の都合で改変が必要な場合は報告して指示を待つ

### 本文

現存12天守とは

明治維新や戦災を越えて天守が現存する城が、全国に12城。石垣の上にそびえる木造の天守には、江戸時代以前の築城技術と時代の重みがある。

日本にはかつて数多くの城が築かれたが、明治の廃城令や戦災、火災によってほとんどの天守が失われた。江戸時代以前に建てられた天守が今も残るのは、次の12城のみである。

めぐり方のヒント

12城のうち4城（丸亀城・松山城・宇和島城・高知城）は四国に集まっており、四国を一周する旅でまとめてめぐることができる。一方、弘前城だけは東北にあり、他の11城と大きく離れている。全城踏破を目指すなら、地域ごとにいくつかの旅に分けて計画するのが現実的である。

よくある質問

Q. 現存天守と復元天守は何が違うのか。
現存天守は江戸時代以前に建てられた天守が解体されずに残っているもの。復元天守・復興天守は、失われた天守を後年に再建したものを指す。大阪城や名古屋城の天守は再建である。

Q. 現存12天守はすべて中に入れるのか。
いずれも天守内部が公開されている。ただし修理工事等で公開状況が変わる場合があるため、訪問前に各城の公式情報を確認するとよい。
